## 📌 Overview

This repository contains the source code for my personal developer portfolio. Built with a futuristic, obsidian-themed cinematic interface, it highlights my journey as an aspiring Full-Stack Developer, my technical competencies in Python and backend architectures, and my exploratory work in AI agent development.

### 🌟 Highlights
* **Cinematic Dark Theme:** Built with custom glassmorphism, responsive ambient glows, and clean obsidian surfaces.
* **Interactive Visuals:** Lightweight dynamic constellation canvas and a real-time revolving typewriter terminal.
* **Categorized Stack:** Structured matrix detailing Backend, AI/LLM integration, Frontend, and core engineering practices.
* **Zero Overhead:** Completely vanilla architecture (HTML5 + Tailwind CDN + Vanilla JS) with zero heavy build steps required.

---

## 🛠️ Tech Stack & Architecture

### Frontend & Styling
* **Markup:** HTML5 (Semantic Structure)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Utility-first styling & responsive layouts)
* **Icons:** [Font Awesome](https://fontawesome.com/)
* **Typography:** Plus Jakarta Sans & JetBrains Mono via Google Fonts

### Core Engineering Focus
* **Languages:** Python, JavaScript
* **Backend Frameworks:** FastAPI, Pydantic
* **AI & Agent Systems:** Pydantic AI, Tool Calling, Schema Validation
* **Databases & Queues:** PostgreSQL, SQL, Celery (Async Task Processing)
* **Developer Tools:** Git, GitHub, VS Code, Postman
